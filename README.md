# Shoebox Cube

Build a balanced, singleton Magic: The Gathering draft cube from the cards you already own.

Everything runs in your browser; your collection never leaves it.

Card data and images: [Scryfall](https://scryfall.com). Draft data: [17lands](https://www.17lands.com) public datasets. Reference cubes: [CubeCobra](https://cubecobra.com).
