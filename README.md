# Shoebox Cube

Build a balanced, singleton Magic: The Gathering draft cube from the cards you already own.

Everything runs in your browser; your collection never leaves it.

Card data and images: [Scryfall](https://scryfall.com). Draft data: [17lands](https://www.17lands.com/public_datasets) public datasets, licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); converted here into per-set win-rate percentiles. Reference cubes: [CubeCobra](https://cubecobra.com). Combos: [Commander Spellbook](https://commanderspellbook.com).
